# Dielcha-Digilab

This is the website I built specifically for the engineering services that I offer to clients and for learning purposes. It has better engineering resources for hobbyists, students, engineers, startups and companies.

## Development

You need Node.js/Bun installed.

```sh
git clone https://github.com/HenryOyoto/Dielcha-Digilab.git
cd Dielcha-Digilab
bun install
bun run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
